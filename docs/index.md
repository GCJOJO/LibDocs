# LibLib and other Libraries

The goal of these libraries is to add RPG style features into Minecraft

## What is LibLib

LibLib is the core library.<br>
It adds stuff such as a Tweening System, UI and Math Utils, and much more !<br>

More info [here](LibLib/index.md)

## What is BlablaLib

BlablaLib is a library used to make custom dialogues inside of Minecraft.<br>
It can be used as a Mod Dependency or directly with Datapacks<br>

More info [here](BlablaLib/index.md)

You can write and preview your dialogues with the [BlablaLib Editor](https://gcjojo.github.io/BlablaLib-Editor/) ([how to use it](BlablaLib/tutorials/3-dialogue-editor.md)).
