# List of Easings

The easings in the library have been based off of [easing.net](https://easings.net/).

## Simple Easings

### Linear

id : `linear`<br>
No easing. The animation progresses at a constant speed.

### Constant

id : `constant`<br>
The progress will be 0 until the end of the animation, where it will jump to 1.
